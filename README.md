# WEB_GIS_GMT458


This is my personal web page project developed for the GMT 458 Web GIS course.

## Live Link
- GitHub Pages: https://ozgeozdmr.github.io/WEB_GIS_GMT458/

## Features
- **Pages:** Home, Biography, CV, Social Media, Maps, Pins, and Favorites.
- **Web GIS:** Included both Leaflet and OpenLayers maps.
  - Resolved overlapping markers using a zoom threshold (markers show up at zoom 5+).
  - Prevented earth repetition when zooming out (`noWrap` and `wrapX: false`).
- **Design & UI:** Added an image carousel animation, customized buttons, circular/rounded map containers, and tabular social links.
